# Docker Container Deployment

This folder contains material for Task 4.1 of SWE40006 – Software Deployment and Evolution.

The deployment involved configuring Docker Desktop on a Windows host using the WSL 2 backend. 
The Docker runtime was verified before the official hello-world image was retrieved from Docker Hub. 
The hello-world image was then successfully executed as a container through Windows PowerShell.


## Deployment Components

- Docker Desktop
- Docker Engine
- Docker CLI
- Docker Hub
- Windows Subsystem for Linux (WSL 2)
- Windows PowerShell
- hello-world container image


## Repository Files

- `docker-commands.txt` – Contains non-sensitive Docker and WSL commands used for execution and verification.

Sensitive information (Docker credentials, authentication information) has been deliberately excluded.
